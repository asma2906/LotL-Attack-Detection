This folder contains the Jupyter notebooks used for data preprocessing, short-sequence LSTM, and long-sequence LSTM implementation.
## LSTM Implementation

This notebook contains two LSTM models for detecting Windows Living-off-the-Land (LotL) attacks.

- Short-Sequence LSTM: 5 events.
- Long-Sequence LSTM: 20 events.

## How to Run

1. Open Google Colab.
2. Upload Cyber_Security_Project_(2).ipynb.
3. Add combined.csv and scenario_manifest.csv to the Cybersecurity_D2 folder in Google Drive.
4. Connect Google Drive.
5. Run all notebook cells in order.

Both models are evaluated using accuracy, precision, recall, F1-score, false-positive rate, and confusion matrices.
